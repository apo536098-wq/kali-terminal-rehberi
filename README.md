## 🚀 Kali Linux Nedir?
Kali Linux, sızma testleri (penetrasyon testleri), adli bilişim ve siber güvenlik araştırmaları için özel olarak geliştirilmiş Debian tabanlı bir Linux dağıtımıdır. İçerisinde yüzlerce hazır güvenlik aracı barındırır.

---

## 📂 Temel Terminal Komutları

| Komut | Açıklama | Örnek Kullanım |
| :--- | :--- | :--- |
| `pwd` | Bulunduğun dizini (klasörü) gösterir | `pwd` |
| `ls` | Klasör içindeki dosyaları listeler | `ls -la` |
| `cd` | Klasör değiştirir | `cd Desktop` |
| `mkdir` | Yeni klasör oluşturur | `mkdir YeniKlasor` |
| `touch` | Yeni boş dosya oluşturur | `touch notlar.txt` |
| `rm` | Dosya siler | `rm notlar.txt` |
| `cat` | Dosya içeriğini terminalde okur | `cat notlar.txt` |
| `sudo` | Yönetici (root) yetkisiyle komut çalıştırır | `sudo apt update` |
